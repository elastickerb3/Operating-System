<h1>Potato OS</h1>
<h2>Was hat es für funktionen?</h2>
<li>Ein Scrollenden Textbildschirm
<li>Eine neustart und herunterfahr funktion
<li>Eine funktion die Farbe zu wechseln

<h2>Unterstütz mein gerät das Potato Os?</h2>
<h3>Benötigte Architectur etc. :</h3>
<li>64 Bit System
<li>Uefi Firmware
<li>Einen Computer

<h2>Wie installiere ich das Potato OS</h2>
<h3>Rufus:</h3>
Lade sie sich <a href="https://rufus.ie/de">Rufus</a> herunter, wähle den USB stick aus und wähle als .iso/.img die .img herunter.<br>
Danach drücken sie auf Starten. Dan gehen sie in die UEFI-Firmware Einstellung und dann wählen sie den USB Stick aus.

<h3>Ventoy:</h3>
Laden sie sich <a href=https://www.ventoy.net/en/download.html>Ventoy</a> herunter, starten sie es und wählen sie den USB Stick aus. Wen sie das getahn haben drücken sie auf Starten.<br>
Wen der USB Stick erfolgreich formatiert wurde schiben sie die .img datei in den USB Stick rein und gehen sie in die UEFI-Firmware Einstellugen und dann wählen sie den USB Stick aus.

<h2>Wo lade ich mir die .img datei herunter?</h2>
Drücken sie auf Realeses und wählen sie die neuste version aus. <br>Wen sie die Version ausgewählt haben drücken sie auf download und befolgen sie die Anderen Schritte.
